# DS-160 提交前检查：中文社区经验汇总（H-1B 视角）

整理自小红书、一亩三分地、知乎、寄托的公开帖子，以及 travel.state.gov 和律所对官方公告的转述，2026-09 更新。
带 `backhome` 规则编号的条目，可以用 `ds160 run <APP>` 自动检查，结果写入 `PREFLIGHT.md`。

> 社区经验不等于官方规定。标注「官方」的条目请以 travel.state.gov 为准。

## 1. 小红书《美签DS-160提交前，检查这22个拒签点》（规则 P01–P22）
1. 只有 "Full name in native alphabet" 一栏写中文，其余全部用英文（P01）
2. 拼音与护照一致，姓和名别颠倒（P02）
3. 中文电码用标准码，每个字 4 位（P03）
4. 没提交的表只保留 30 天，登录并 Save 一次可以续期（P04）
5. SSN 和纳税人识别号没有就选 Does Not Apply（P05）
6. 出行计划写清楚（P06）
7. 在美住址不能空（P07）
8. 美国联系人要真实，没有就填酒店，不要编造（P08）
9. 社交账号手动添加：列表里没有的平台（微信、小红书、抖音）填到 other websites，写英文或数字 ID（P09）
10. 所填账号设为公开（P10，对 H-1B 属实，见下文第 2 节）
11–13. 护照号、日期、签发地和护照首页完全一致（P11–P13）
14. 在美直系亲属如实填写（P14）
15–16. 职业、收入、公司名称和地址与在职证明一致（P15–P16）
17. 敏感岗位只写日常工作内容（P17）
18. 学历至少填最近两段，专业写全称（P18）
19. 家庭住址填现住址，不填户口地址（P19）
20. 过去 5 年去过的国家和地区一个不漏（P20）
21. 安全背景问题逐题读，没有特殊情况选 No（P21）
22. 提交前通读一遍（P22）

## 2. H-1B 专项
- **社交媒体公开（官方）**：2025-12-15 起，线上审查扩展到 H-1B/H-4。北京面签后有人被签证官当场提醒把账号设为公开。
- **社交媒体报全**：上海有申请人只填了 LinkedIn，被 221(g) 要求补报。补报时必须一路点到最后重新提交，生成新的确认页，只点 Save 不算（C11）。
- **面签地点（官方）**：原则上在国籍国或居住国面签。北京、上海、广州、沈阳、武汉都有 H-1B 面签的经验帖。DS-160 上的城市和实际面签城市不同，有人反馈不影响（C06）。
- **提交时限**：广州要求面签前至少 3 个工作日提交 DS-160，否则会取消预约。新的预约系统在预约之后不能更换 DS-160，预约前要定稿（C10）。
- **系统 bug**：新系统自动填充美国地址时，可能把"出生国家"改成美国，有好几例报告（C09）。
- **以往雇主**：过去 5 年的雇主都列出来，包括 OPT 雇主和实习，避免时间线出现空白（C04）。
- **专业组织**：IEEE、ACM 等会员属于"组织"一题（C05）。
- **兵役**：大学军训不算兵役。specialized skills 一题指武器、爆炸物、核生化方面的训练，CS 背景一般答 No。
- **CS/STEM 背调（MANTIS/TAL）**：被 check 的比例高，通常需要 60–90 天。带一页简历，写清项目内容、有无接触出口管制技术。行程留足缓冲。
- **Amendment**：律所经验是带新的 approval notice 去面签即可，不用改 DS-160。
- **10 万美元费用**：在美国境内从 F-1 转 H-1B（change of status）获批的，出境办签证不触发这笔费用。带上 I-797 身份变更批准页作为证明。

## 3. 面签当天
- **需要打印的材料**：DS-160 确认页、预约确认页（不是付款收据）、I-797 原件、护照，以及新旧照片备用
- **照片**：窗口会检查照片，不合规要重拍。北京使馆内的拍照点约 50 元现金
- **入场**：北京按先到先排，不严格按预约时间，至少预留 3 小时
- **取件**：选 delivery 比 pickup 省事
- **小错误**：小的 typo 可以在信息核对窗口现场修改，不必重新提交 DS-160

## 流言与事实
- **"填错只能重交签证费"**：假。可以重新填一份 DS-160 并更新条码；签证费收据 365 天内有效
- **"DS-160 问是否党员"**：假。DS-160 上没有这道题（DS-260 上有）；面谈中签证官仍可能问
- **"军训算服兵役"**：假
- **"漏报社媒必然终身禁入"**：过度夸大。构成失实陈述要求故意且重要，但仍要报全
